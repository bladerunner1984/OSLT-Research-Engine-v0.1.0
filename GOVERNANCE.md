# OSLT Governance

## Authority lattice

| Level | Meaning |
|---|---|
| A0 | Scientific constitution |
| A1 | Authorised specification / preregistration |
| A2 | Human governance or expert decision |
| A3 | Verified computation or disclosure-checked result |
| A4 | Accepted analysis artefact |
| A5 | Model or analyst proposal |
| A6 | Raw history / unadjudicated material |

Lower authority cannot overwrite higher authority. Constitution, consent, ethics, legal-basis and
release decisions are protected types.

## Required procedural roles

- primary analyst;
- rival analyst;
- methods critic;
- source verifier;
- human reviewer when risk triggers fire.

Model agreement is not replication and contributes no evidential weight.

## Release rule

No high-impact claim is released unless provenance, dependency, counterevidence, certainty,
continuity, reproducibility and human-review gates are complete.
