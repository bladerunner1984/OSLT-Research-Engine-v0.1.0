# OSLT Pilot 2 — Referral and Change-Point Decomposition

## Primary question
What changed in recorded gender-related referrals/presentations, when, in whom, and how much can demographic, coding, service-capacity, access and ascertainment changes explain before invoking other mechanisms?

## Sequence
1. Define separate outcomes: survey identity, distress, primary-care presentation, specialist referral, treatment request/initiation.
2. Build age-sex-region denominators.
3. Harmonise coding/service definitions by era.
4. Detect change points without selecting dates from the preferred narrative.
5. Standardise/decompose demographic and case-mix contributions.
6. Overlay service openings, referral criteria, waiting lists, guideline/policy dates and administrative coverage changes.
7. Use interrupted time series/event study/DiD/synthetic controls where defensible.
8. Replicate using independent jurisdictions/datasets.

## Gate
No social/institutional mechanism is allocated population contribution until ascertainment/service alternatives have been quantified.
