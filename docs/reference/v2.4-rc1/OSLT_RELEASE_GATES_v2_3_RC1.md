# OSLT v2.3 release gates

A high-level scientific result is not releasable until the applicable gates pass:

- objective lock valid;
- causal specification versioned, preregistered and frozen for confirmatory work;
- balanced Counter-RAG evidence pack;
- temporal/jurisdiction/concept review;
- evidence dependency review;
- discovery completeness/saturation review;
- primary model qualification;
- multi-analyst adversarial harness complete;
- substantive cross-kernel contradictions resolved or explicitly retained as unresolved;
- certainty vector complete;
- atomic claims evidence-verified;
- human expert review completed when escalation rules require it;
- reproducibility manifest valid;
- execution budget/circuit-breaker status clean;
- Global-100 architecture audit pass;
- Global-100 executable assurance overlay pass.
