# OSLT DPIA and Ethics Readiness Checklist

- [ ] Sponsor/controller roles identified
- [ ] Research purpose/public benefit defined
- [ ] Special-category and child-data issues reviewed
- [ ] Lawful basis/condition documented by responsible institution
- [ ] Necessity and proportionality assessed
- [ ] Minimum necessary fields frozen
- [ ] Alternatives using less sensitive data considered
- [ ] Consent/assent route defined for primary research
- [ ] Third-party communication risk addressed
- [ ] Re-identification risk assessed
- [ ] Data linkage risk assessed
- [ ] Security/TRE architecture specified
- [ ] Retention/deletion specified
- [ ] Safeguarding procedure defined
- [ ] Independent ethics/scientific review obtained where required
- [ ] Output disclosure control specified
