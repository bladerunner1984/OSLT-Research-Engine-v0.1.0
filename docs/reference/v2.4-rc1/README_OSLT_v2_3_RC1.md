# OSLT Research Engine v2.3 RC1

This release hardens OSLT's graph-orchestrated multidisciplinary research engine around model
qualification, causal-specification versioning, evidence completeness/saturation, contextual
contradiction resolution, human-review escalation, execution budgets, epistemic-status labelling,
and a fail-closed release gate.

Key retained assets: 640-variable ontology; 100 analytical method families; 15 domain kernels;
65 registered source families; 640 variable-to-method mappings; 640 variable-to-source mappings.

Validation claims in this package concern architecture/test completeness only. They are not evidence
that any substantive hypothesis is true and are not external clinical or scientific validation.
