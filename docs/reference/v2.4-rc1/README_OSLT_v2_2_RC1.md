# OSLT Research Engine v2.2 RC1

OSLT v2.2 is a governed multidisciplinary scientific-investigation engine. It combines the v2.1 evidence fabric, causal and interpretive kernels, certainty/claim controls and Global-100 audit with explicit graph orchestration and a model-agnostic execution policy.

## v2.2 execution principles

1. **Multi-agent does not require multi-model.** The default is `SINGLE_PRIMARY`.
2. **Model agreement is not evidential replication.** Scientific independence comes from evidence, design, blinding, rivals and replication.
3. **Nodes have contracts; edges carry data.** Deterministic plumbing is code, not LLM work.
4. **Independent work fans out.** Retrieval lanes and analyst roles run independently before explicit barriers.
5. **Verifier gates precede synthesis/release.** Findings must survive adversarial review and atomic claim verification.
6. **Cycles must converge.** Discovery loops stop after bounded rounds/dry rounds and deduplicate against all seen findings.
7. **Sensitive-data governance overrides benchmark rank.** A model endpoint must be approved for the data class before raw protected data can be processed.
