# OSLT v2.4 RC1 Re-engineering Changelog

## Release objective
Move OSLT from a mature reasoning/evidence-fabric architecture into an empirical research execution system with explicit data acquisition contracts.

## Added
- 64-proposition competing-model registry spanning intrinsic/recognition, multifactorial developmental-institutional, ascertainment/service, mixture/heterogeneity and null/alternative explanations.
- 640-row field-level harvest dictionary; all field availability explicitly starts unverified.
- 65-source operational harvest register.
- 13 workstream runbooks.
- Data contracts, harvest governance and evidence-ingest record code.
- Adaptive sample-size / attainable-inference utilities.
- Empirical-study preparation binding engine plan + harvest readiness + inference envelope.
- Restricted-data/TRE, participant-consent and provenance standards.
- Pilot protocols for academic knowledge production, referral change-points and developmental heterogeneity.
- Research governance/application/SAP templates.
- Thesis-mechanism import note with hypothesis-only boundary.
- Global-100 executable assurance expanded from 20 to 25 probes.

## Anti-drift result
- Global-100 architecture: 100/100.
- Executable assurance: 25/25.
- Inherited scientific controls: 16/16 reachable.
