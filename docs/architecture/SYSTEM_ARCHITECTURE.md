## Master-kernel rule

The master synthesis layer does not vote over prose reports. It consumes versioned `KernelResult`
objects with aligned construct, population, period, jurisdiction and estimand. Results sharing a
cohort, dataset, code lineage or research family are dependency-collapsed before synthesis.

## Data boundary

Raw controlled person-level data never enter the common repository or central evidence store. The
cross-environment contract is an approved analysis specification plus a disclosure-checked result.
